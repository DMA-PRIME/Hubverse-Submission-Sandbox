# Maintainer checklist before publishing

- [ ] Confirm the final repository owner and name.
- [ ] Add an explicit license.
- [ ] Review `hub-config/` with current Hubverse schema tooling.
- [ ] Review the pull-request workflow and pin actions if required by policy.
- [ ] Enable branch protection for `main` and require the validation check.
- [ ] Decide whether first-time contributors need approval to run workflows.
- [ ] Decide whether to close and retain practice pull requests or merge them.
- [ ] Add a cleanup policy for accumulated practice outputs.
- [ ] Test website, Desktop, and terminal paths from a student account.
- [ ] Replace the placeholder repository name in the companion HTML after publishing.
