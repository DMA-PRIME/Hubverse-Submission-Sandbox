# Practice model output

Put each submission in:

```text
model-output/<model_id>/<round_id>-<model_id>.<extension>
```

The folder and the model ID suffix in the filename must match exactly. Use the uniquely named synthetic CSV generated by the companion guide. Do not upload a real forecast or scenario output to this public repository. The checked-in `student-demo` output is a reserved example and should not be changed.

This sandbox teaches paths and pull-request mechanics. Passing its checks does not establish compliance with any operational hub.
