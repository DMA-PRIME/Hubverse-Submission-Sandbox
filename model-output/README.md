# Practice model output

Put each submission in:

```text
model-output/<model_id>/<round_id>-<model_id>.<extension>
```

The folder and the model ID suffix in the filename must match exactly. Use `practice-files/forecast-example.csv` or `practice-files/scenario-example.csv` as a teaching example.

This sandbox teaches paths and pull-request mechanics. Passing its checks does not establish compliance with any operational hub.
