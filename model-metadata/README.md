# Model metadata

Every practice model has one YAML file:

```text
model-metadata/<team_abbr>-<model_abbr>.yml
```

The filename stem must equal `model_id`, and `model_id` must equal `team_abbr-model_abbr`.

Use the uniquely named synthetic YAML generated by the companion guide. Do not upload real model metadata or personally identifying information to this public repository. The checked-in `student-demo.yml` is a reserved example and should not be changed.

Operational hubs usually require additional fields; their current metadata schema is authoritative.
