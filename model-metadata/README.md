# Model metadata

Every practice model has one YAML file:

```text
model-metadata/<team_abbr>-<model_abbr>.yml
```

The filename stem must equal `model_id`, and `model_id` must equal `team_abbr-model_abbr`.

Copy the example from `practice-files/student-demo.yml`. Operational hubs usually require additional fields; their current metadata schema is authoritative.
